# Guías Global-VZLA

Guías paso a paso para usar la herramienta Global-VZLA, escritas para quien empieza de cero.

Se leen en: https://pablo-navarreto.github.io/globalvzla-guias/

## Cómo se publica

Las guías están en `docs/` (Markdown). El sitio se arma con MkDocs Material:

```bash
pip install mkdocs-material
mkdocs serve      # para mirarlo en la PC
mkdocs gh-deploy  # para publicarlo (rama gh-pages)
```

Las fotos no llevan datos personales: nombres, correos e IDs son de ejemplo.
